# Clapperboard sample

Source: [Clapperboard, BigSoundBank #1011](https://bigsoundbank.com/clapperboard-s1011.html), Joseph SARDIN. The author dedicates this recording to the public domain under CC0. Downloaded 2026-09-14 from the linked MP3 download on that page.

The app uses the third isolated strike, with a short pre-attack, normalized level and tapered tail. `tools/review7-assets.mjs` creates the mono 44,100 Hz signed 16-bit PCM asset from the decoded source. Playback resamples that real strike at the selected pitches and mixes the complete phrase into one buffer. This license applies to this sound, not to the CLAPPA project.
