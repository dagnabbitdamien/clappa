## Historical development notes

The numbered `test*.md`, `release*.md` and `review*/` files record work and validation for particular builds. The `mockups/` directory and earlier artwork notes record design exploration. These are retained for reference, rather than as current installation instructions or a list of present features.

Some historical reports link to local review pages or excluded screenshots and recordings. Those artifacts are not part of the public repository. Start with the current release notes and architecture above when an older report describes different behavior.
