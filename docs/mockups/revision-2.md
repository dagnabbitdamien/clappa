# Landscape alternatives

The first sheet was rejected by the owner for its mascot and portrait presentation. New owner direction: landscape by default and an ugly-cute Australian brushtail possum, with brown eyes and a dark tail.

Three separate built-in image generations:

- `01-weathered-cinema.png`: worn slate and detailed scruffy animal.
- `02-scruffy-cartoon.png`: illustrated possum and olive accents.
- `03-deadpan-graphic.png`: simplified animal and bold slate typography.

Each shows main app, verification, and OBS tile. No design is approved. Images remain conceptual: placeholders are not working QR proof, opening/closing geometry needs implementation review, and unsolicited decorative copy in option 1 should be removed. The mascot illustrations still need owner review for species likeness.

Natural-history visual references were searched using Australian common brushtail possum; reference page: https://www.alburycity.nsw.gov.au/services/pets-and-animals/local-wildlife/mammals/common-brushtail-possum . No reference photograph was copied into the artwork.
