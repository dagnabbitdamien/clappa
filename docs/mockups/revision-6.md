# Fixed geometry mockups

Complete alternatives: `07-option-a.png`, `07-option-b.png`, `07-option-c.png`. Each contains portrait, landscape, and OBS views. Compare them in `07-fixed-layouts.html`.

Screen geometry is set directly in CSS: portrait 300 by 643.333333, landscape and OBS 643.333333 by 300, matching the 1440:3088 S22 Ultra screen ratio. CLAPPA logo is larger than Tap to clap. Photo and QR remain illustrative placeholders, not live proof. These are design artifacts only, not Android implementation.

Mascot assets were generated separately using the built-in image tool with `brushtail-reference.jpg` as anatomy reference, then placed into the layouts. Options A/B/C vary in mascot simplification and mint/apricot/sage accents. All remain subject to owner review.

Prompt base: Single isolated Australian common brushtail head and upper chest on transparent background, clean friendly vector-style cartoon based on reference anatomy, no realistic fur, grey forehead, brown eyes, tapered dark muzzle and pink nose, cream chest. Option A rounded five-colour sticker; B gently chibified cheeky adult; C very simple broad flat shapes and smaller eyes/ears.
